# ETS2 Lane Guide — 내비·차선·신호 HUD

게임 GPS 경로를 따라 **다음 방향 화살표와 거리**를 보여 주는 작은 인게임 안내창입니다. 교차로에 가까워지면 추천 차로를 노란색으로 강조하고, 실제 신호 데이터가 확인되면 신호 색과 남은 초를 별도 줄에 표시합니다. 티맵의 초록색 방향 영역·큰 거리 숫자·검정 차로 표시줄 구성을 참고했으며, 지도 화면과 음성은 없습니다. **C++ DLL 안에서 지도·경로 연결, 화면 표시, 신호 수신을 처리하므로 Electron이나 별도 수신 프로그램을 실행할 필요가 없습니다.**

이 저장소에는 소스, 테스트, 의존성 패치와 문서만 포함합니다. 게임 추출 데이터, DLL·EXE 빌드 결과, 개인 설정, 로그와 로컬 바로가기는 제외합니다. 새 환경에서는 [소스 빌드 준비](docs/build-from-source.md)를 먼저 진행하세요.

## 지금 사용하기

1. 평소처럼 ETS2를 DirectX 11로 실행합니다. 게임이 표시하는 SDK 안내를 확인합니다.
2. **게임 지도에서 목적지와 경유지를 설정합니다.** 안내창은 게임 내비게이션의 경로를 읽어 따라갑니다. 별도로 도시를 선택하지 않습니다.
3. **F8**로 안내창 위치를 바꿉니다. 상단·하단의 좌측·중앙·우측, 총 6개 프리셋을 순환하며 위치와 크기는 다음 실행에도 유지됩니다.

`.scs` 모드 관리자가 아니라 게임의 `bin/win_x64/plugins`에서 DLL을 읽습니다. DX11 화면에 직접 그리므로 외부 창을 위한 화면 모드 변경은 필요하지 않습니다. 외부 앱 자동실행, 시작 프로그램, 서비스, 예약 작업은 추가하지 않았습니다.

| 키 | 동작 |
| --- | --- |
| F8 | 다음 위치 프리셋 |
| Ctrl+F8 | 이전 위치 프리셋 |
| Shift+F8 | 크기 순환 (70·100·120·140·160·180%) |
| F9 | 안내창 표시 / 숨기기 |
| F10 | 단축키·현재 설정 안내 열기 / 닫기 |
| Esc | 단축키 안내 닫기 |

F10은 마우스로 조작하는 창이 아니라 현재 위치·크기·단축키를 보여 주는 패널입니다. 마우스 입력을 가져가지 않으며 게임 커서를 그대로 사용합니다. 패널을 닫아도 차선 안내는 유지됩니다. 게임 종료 시 함께 종료됩니다. 인게임 입력 처리는 Win32 메시지를 사용하므로 게임의 DirectInput 단축키까지 차단하지는 않습니다. 현재 게임 설정의 F10 스크린샷 동작이 함께 발생할 수 있습니다.

기존 **차선 안내 실행.lnk / 미리보기.lnk**는 외부 Electron 버전입니다. 디자인 시연용으로 남겨두었으며 인게임 버전 사용 시에는 실행하지 않아도 됩니다. 외부 버전만 사용할 때는 테두리 없는 창 모드가 필요할 수 있습니다.

## 현재 범위

- 이 PC에 설치된 **ETS2 1.61.1.0**에서 추출한 지도: 도시 78개, 도로 구간 38,119개.
- **게임이 선택한 GPS 경로를 읽어 차선 안내에 반영합니다.** 게임에서 목적지·경유지·우회 경로를 바꾸면 갱신하고, 경로를 지우면 안내도 중단합니다. 동기화는 게임→안내창 한 방향이며 게임 경로를 변경하지 않습니다. 회사·도시의 목적지 이름을 별도로 표시하는 기능은 없습니다.
- 교차로 프리팹의 AI 차로 연결 데이터를 따라 해당 출구에 도달할 수 있는 진입 차로를 계산합니다. 불확실한 도로 위치, 반대 방향, 고도 불일치, 차로 수 불일치에서는 추천을 숨깁니다.
- 다음 방향·거리 안내는 차선 표시와 별개입니다. 한 차로 교차로나 차선 선택이 아직 필요하지 않은 먼 분기점에서도 확인된 경로의 방향을 표시합니다. 진입 차로 구조가 확인되는 가까운 분기점에만 차선 줄을 추가합니다. 모든 교차로를 지원하지 않으며 현재 주행 중인 차로 번호는 판별하지 않습니다.
- 게임의 도로 노드 ID를 추출 지도의 연결과 대조합니다. 모르는 도로·페리·유로터널·회사 내부처럼 연결을 확인하지 못한 구간은 임의의 다른 경로로 대체하지 않습니다. 알려진 구간 끝에서는 안내를 중단하며 목적지 도착으로 처리하지 않습니다. 트럭이 경로 밖에 있거나 반대 방향을 보고 있을 때도 추천을 숨깁니다.
- 안내 거리는 지도 좌표에서 계산한 **실제 게임 공간의 미터**이며 1,000m 이상은 km로 표시합니다. 축척이 적용된 게임 GPS 잔여 거리와는 다릅니다. 다음 방향은 확인된 경로에서 미리 보여 주고, 차선 표시는 속도에 따라 약 12초 전, 최대 450m 전부터 시도합니다.
- 게임 지도 업데이트·지도 DLC 추가 시 데이터를 다시 추출해야 합니다. ProMods 등 외부 지도는 지원하지 않습니다. 네이티브 DLL은 실행 파일의 버전과 추출 지도의 버전이 다르면 안내를 중단합니다.
- 미리보기는 합성된 시연 경로이며 안내창에 항상 시연 표시가 붙습니다. 네이티브 테스트 호스트는 **시연 · 실제 주행 아님**, 신호 샘플은 **시연 신호**로 표시합니다.
- **신호등 잔여 시간 연동은 실험 기능**입니다. ETS2LA의 ETS2 1.61용 읽기 전용 로컬 빌드가 실제 신호 상태를 제공하며, 게임 GPS와 연결한 경로·신호 ID·지도 위치가 일치할 때만 표시합니다. 신호등만 보려는 경우에도 게임 지도에서 목적지를 설정해야 합니다.
- 신호의 초 표시는 **현재 색에서 다음 상태로 전환될 때까지**입니다. 빨간불 뒤에 빨강+노랑이 올 수 있으므로 출발 허용까지 남은 시간과 같지 않습니다. 타이머 정지, 연결 끊김, 일시 정지, 다른 방향·서로 충돌하는 신호는 숨깁니다. 신호를 확인할 수 없는 교차로에서는 표시되지 않습니다.

## 확인한 것과 아직 남은 것

- 새 C++ 버전: 경로·위치·다음 방향·차선·신호 정지선 검사 19개, 실제 지도 차선 안내 **8,921 / 8,921**, 차선 정보 없이 방향만 안내하는 진입 샘플 **12,496 / 12,496** 통과. 신호 수신기 **13개 테스트 묶음 / 115개 검증** 통과.
- 게임 GPS 수신·재탐색·취소·지도 연결 검사 **22개** 통과. 실행 중인 게임에서 읽은 경로 61개 노드를 합성된 도로 위 위치로 재생해 **연속된 도로 연결 76개**를 확인했습니다. 실제로 캡처한 트럭은 경로에서 57m 떨어져 반대 방향을 보고 있어 안내를 숨겨야 하는 사례로 검사했습니다. 전체 재생 검사 **100개** 통과이며 실제 주행 검증은 아닙니다.
- 테스트 호스트에서 F8·Ctrl+F8 위치 순환, Shift+F8 크기 변경, 재시작 후 우측 하단·120% 복원을 시각 확인했습니다. F10 패널은 마우스를 받지 않습니다.
- 네이티브 DX11 테스트 호스트에서 실제 DLL을 로드해 **151프레임 직접 렌더링, ResizeBuffers, 원래 렌더 타깃 복원, SDK 종료 후 렌더링 중단** 확인. 한글 안내창과 F10 설정 창 시각 확인. 테스트 호스트는 ETS2가 아니며 합성 경로에 명시적인 테스트 표시를 붙입니다.
- 통합 HUD의 먼 거리 화면에서 `1.2 km`·방향 화살표만 보이는 간결한 배치를 시각 확인했습니다. 신호 시연을 포함한 렌더링 자동 검사는 통과했으며 세 정보가 모두 보이는 배치의 최종 육안 검사는 남아 있습니다.
- 기존 인게임 버전은 **실제 ETS2 1.61.1.0 / DX11 / 3840×2160** 시작 화면에서 DLL 로드, 초록색 안내창, F10 설정 열기, F9 숨기기·다시 표시를 확인했습니다. Electron·외부 신호 reader·테스트 호스트가 모두 종료된 상태로 확인했습니다. 이번 통합 버전의 실제 운전·교차로 검증은 아직 별개로 남아 있습니다.

- 동작 테스트: 차선 선택, 반대 방향·고가도로 구분, 지나간 안내 제거, 차로 수 변화, 통신 단절·잘못된 패킷, 단방향 경로, 여러 도로 구간에 걸친 사전 안내, 신호 시연의 모드 격리·전환·잘못된 시각 처리, 경로별 신호 선택·정지선 통과·잔여 시간 데이터 검증.
- 실제 추출 지도에서 차로 수가 일치하는 진입 샘플 **8,921건**의 안내 생성 성공. 이는 데이터 기반 검사이며 8,921곳을 직접 운전했다는 뜻은 아닙니다.
- 베를린→함부르크, 파리→리옹, 런던→도버 경로 계산 성공.
- 빌드한 DLL을 테스트용 SDK 호스트에 로드하여 위치·방향·속도·일시 정지·종료 UDP 전송 확인.
- Windows 창에서 좌·우 미리보기 전환, F8 고정 전환, 실제 주행 모드의 연결 대기·차선 숨김 확인.
- 전체 동작 테스트 **25개 통과**. 테스트용 Win32 공유 메모리에서 신호 수신·감소 확인, 멈춘 타이머 숨김, 송신 종료 후 연결 해제 확인. 실제 게임 신호를 사용한 검사는 아닙니다.
- 티맵 스타일 안내창의 신호 시연 표시 및 실제 주행 전환 시 시연 숫자 제거 확인.
- **ETS2를 직접 운전하면서 추천 차선·실제 신호와 잔여 시간의 일치 여부를 확인하는 테스트는 아직 하지 않았습니다.** 첫 주행에서는 도로 표지판·게임의 실제 신호와 비교하며 확인해 주세요.

## 설치된 파일

게임 내부 `.scs` 모드의 가능 범위는 [게임 내부 UI 조사](docs/in-game-ui.md), 신호등 데이터의 한계와 시연 구현은 [신호등 조사](docs/traffic-signals.md)에 정리했습니다.

새 인게임 플러그인:

`C:\Program Files (x86)\Steam\steamapps\common\Euro Truck Simulator 2\bin\win_x64\plugins\ets2_lane_ingame.dll`

지도는 같은 `plugins` 폴더의 `lane_guide/map.bin`입니다. 새 안내창만 제거하려면 게임을 종료하고 `ets2_lane_ingame.dll`과 `lane_guide` 폴더를 제거합니다. 위치 프리셋과 크기는 `%LOCALAPPDATA%\ETS2LaneGuide\native-layout.ini`에 저장합니다. 이전 `native-ui.ini`의 픽셀 위치는 사용하지 않습니다. 테스트 호스트는 별도의 `render-test-layout.ini`를 사용합니다.

신호·GPS 데이터 플러그인(ETS2 1.61.x 전용): 같은 폴더의 `ets2la_plugin.dll`. ETS2LA 공개 소스를 빌드했으며 조향·가속 제어 호출을 제거했습니다. 같은 길이의 재탐색과 경로 취소도 반영하도록 수정하고, 발행 시각·갱신 번호가 있는 전용 GPS 출력을 추가했습니다. 지도에서 연결된 신호 진입 경로는 6,838개이며, 실제 런타임 신호와 매칭되는 범위에서만 표시합니다. 게임 업데이트 후에는 해당 버전에 맞는 플러그인·지도 검증이 필요합니다.

기존 `.scs` 모드와 세이브를 편집하지 않습니다. 예전 외부 버전용 `ets2_lane_guide.dll`도 남아 있으며 새 인게임 버전은 이를 필요로 하지 않습니다. GPS·신호 데이터 플러그인도 제거하려면 `ets2la_plugin.dll`을 제거합니다. 외부 앱의 설정 파일은 `%APPDATA%\ets2-lane-guide\settings.json`입니다.

인게임 버전은 프로세스 내부에서 위치를 받고 로컬 공유 메모리로 GPS·신호를 읽습니다. 외부 서버나 계정은 사용하지 않습니다. 예전 외부 버전용 DLL만 `127.0.0.1:37539` UDP를 사용합니다. GPS 연결 형식과 범위는 [게임 내비 경로 연동](docs/game-gps-sync.md)에 기록했습니다.

## 개발·재생성

Node.js 24.13 이상, npm 11.6.2 이상, Windows x64가 필요합니다. 네이티브 DLL 재빌드는 Visual Studio 2022 C++·CMake 도구가 필요합니다. SDK와 지도 파서는 저장소에 포함하지 않으며 [소스 빌드 준비](docs/build-from-source.md)에 고정 버전과 준비 명령을 기록했습니다. 아래 명령은 의존성과 로컬 지도가 준비된 이후에 사용합니다.

```powershell
npm install
node node_modules/electron/install.js
npm test
node tools/compile-ingame-map.cjs
powershell -NoProfile -File tools/build-ingame.ps1
powershell -NoProfile -File tools/build-signal-plugin.ps1
.\native\ingame-build\Release\ingame_render_host.exe .\native\ingame-build\Release\ets2_lane_ingame.dll --self-test
.\native\ingame-build\Release\ingame_render_host.exe .\native\ingame-build\Release\ets2_lane_ingame.dll --far
.\native\ingame-build\Release\ingame_render_host.exe .\native\ingame-build\Release\ets2_lane_ingame.dll --signal-demo
powershell -NoProfile -File tools/install-ingame.ps1
powershell -NoProfile -File tools/start.ps1 -Demo
powershell -NoProfile -File tools/build-plugin.ps1
powershell -NoProfile -File tools/build-signal-reader.ps1
powershell -NoProfile -File tools/update-map.ps1
node tools/check-map.cjs
node tools/verify-map.cjs
```

지도 원본은 `data/raw/`, 공통 그래프는 `data/map.json`, C++용 직렬화는 `data/ingame-map.bin`입니다. 지도 파일은 소유한 게임 설치에서 로컬로 추출하며 저장소·배포물에 포함하지 않습니다. 지도 재생성 후 `compile-ingame-map.cjs`와 설치 명령을 실행하고 게임을 다시 시작하세요. 새 지도 형식은 도로 노드 ID를 포함하는 `LNGMAP02`이므로 HUD DLL·지도·GPS producer DLL을 함께 설치합니다. 설치는 게임 종료 상태에서만 가능하며 기존 세 파일은 `output/ingame-backup/`에 백업합니다.
