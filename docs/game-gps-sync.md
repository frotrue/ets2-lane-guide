# 게임 내비게이션 경로 연동

게임 지도에서 설정한 목적지·경유지와 게임이 고른 경로를 차선 안내가 따라가는 한 방향 연결입니다. 별도로 도시를 선택하거나 안내창에서 경로를 다시 계산하지 않습니다. 목적지 회사명·도시명을 표시하는 기능은 포함하지 않습니다. 이전 Electron 버전은 이 변경 대상이 아닙니다.

## 데이터 흐름

ETS2LA의 [고정한 소스](https://github.com/ETS2LA/plugin/blob/7094b334f10b68343d0082f1ef4078669235106b/src/core.cpp)는 `gps_manager.simple_route_source.route_task.physical_route_items`에서 도로 노드 UID와 잔여 거리·시간을 읽습니다. 원본은 경로 길이가 같으면 출력을 갱신하지 않아 재탐색·취소가 누락될 수 있습니다. 로컬 수정에서는 매 tick 새로 읽고, 취소 시 빈 경로를 발행합니다. 입력 제어 호출을 제거한 기존 변경도 유지합니다.

추가 출력 `Local\LaneGuideGPSv1`은 최대 6,000개 노드, 상태, 발행 시각, 갱신 번호를 갖습니다. 생산자는 자신의 공유 메모리에만 쓰며 기존 이름의 mapping을 덮어쓰지 않습니다. HUD는 읽기 권한으로 열고 연속 스냅샷 일치, 짝수 갱신 번호, producer 버전 `1610`, 750ms 이내 발행 시각, 노드 수와 유효 수치를 검사합니다. 읽을 때마다 핸들을 닫으므로 생산자 종료 후 오래된 데이터를 유지하지 않습니다.

`LNGMAP02` 지도에는 원본 도로 노드 UID를 보존합니다. 연속된 GPS 노드 쌍이 지도에서 하나의 방향 있는 도로·프리팹 연결로 확인되어야 사용합니다. 지도에 명시된 동일 UID 경계 연결만 이어 붙이며, 모르는 구간이나 중복 후보는 끊습니다. 트럭의 수평 거리·고도·진행 방향이 맞는 구간부터 안내하고, 길을 임의로 찾아 빈 구간을 메우지 않습니다. 부분 경로의 끝은 도착으로 표시하지 않습니다.

현재 위치는 SDK로 받고, 경로 수신은 약 100ms마다, 지도 연결은 노드가 바뀔 때 또는 1초마다 갱신합니다. 경로 취소·데이터 만료·일시 정지·트럭 위치 해제 시 기존 추천과 신호를 지웁니다. 게임의 경로·목적지·세이브·입력 공유 메모리에는 쓰지 않습니다.

다음 방향·거리 안내는 차선 추천과 분리합니다. 지도 생성 시 두 개 이상의 출구 선택이 있는 프리팹 연결의 회전 방향을 `navigationTurn`으로 보존합니다. 경로에서 다음 결정 지점까지 거리를 계산하므로 한 차로 교차로와 먼 분기점도 안내합니다. 차선 수가 맞지 않으면 차선 줄만 숨기고 확인된 회전 안내는 유지합니다. 이미 지난 교차로의 회전은 지우고 다음 지점으로 넘어갑니다. 확인된 다음 지점이 없으면 거리나 화살표를 만들어 내지 않습니다.

## 검증과 한계

- GPS 단위·공유 메모리 통합 검사 22개 통과: 같은 길이의 재탐색, 취소, 생산자 종료, 만료, 잘못된 패킷, 반대 방향·고도, 불명확한 연결, 부분 경로 끝 처리.
- 내비 엔진 검사 19개, 실제 지도 차선 진입 샘플 8,921개 및 차선 정보 없는 방향 안내 샘플 12,496개 통과. 데이터 기반 검사이며 해당 장소를 직접 운전한 검증은 아닙니다.
- 실제 실행 중인 게임의 경로 61개 노드를 읽어 로컬 fixture로 보존했습니다. 실제 트럭 위치는 첫 GPS 도로에서 57m 떨어져 반대 방향을 보고 있었으며 안내를 거부했습니다. 합성된 도로 위 위치에서 같은 경로를 재생하면 76개 지도 연결을 연속해서 따라갑니다. 확인하지 못한 연결 앞에서 멈추므로 전체 목적지까지 연결되었다는 검증은 아닙니다. 해당 재생 검사는 총 100개 통과했습니다.
- 네이티브 HUD 렌더링·resize·렌더 타깃 복원·종료 검사를 통과했습니다. 위치 프리셋·크기 변경·재실행 후 설정 유지도 테스트 호스트에서 시각 확인했습니다.
- 새 producer와 HUD를 함께 설치한 후 실제 게임에서 목적지 변경·경유지 변경·우회·취소·교차로 진입을 비교하는 주행 검증은 남아 있습니다. 메모리 자료구조는 게임 버전에 의존하며 현재 대상은 ETS2 1.61.1.0입니다.

## 재빌드·설치

`tools/compile-ingame-map.cjs`, `tools/build-ingame.ps1`, `tools/build-signal-plugin.ps1` 순서로 생성합니다. 게임을 완전히 종료한 뒤 `tools/install-ingame.ps1`을 실행하면 HUD DLL·지도·producer DLL을 함께 백업하고 교체합니다. 예전 지도 형식과 새 HUD DLL을 섞어 설치하면 안 됩니다. 외부 앱·서비스·예약 작업은 추가하지 않습니다.

선택적인 캡처 재생 검사는 다음 명령입니다. fixture는 첫 줄에 x/y/z/heading, 이후 줄에 16진수 노드 UID를 갖는 이 작업의 로컬 테스트 데이터이며 게임 세이브가 아닙니다. 이 fixture와 실제 지도는 GitHub에 포함하지 않으므로 기존 로컬 파일이 있을 때만 실행합니다. 기본 CTest의 GPS 검사는 합성 지도·독립 테스트 mapping만으로 실행됩니다.

```powershell
.\native\ingame-build\Release\ingame_gps_test.exe .\data\ingame-map.bin .\output\game-route-fixture.txt
```
